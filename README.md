## 📌 Project Overview

This project focuses on analyzing customer retention and churn behavior using the Telco Customer Churn dataset.

The objective is to identify factors influencing customer churn and provide business insights through an interactive Power BI dashboard.

---

## 🎯 Objectives

- Analyze customer churn patterns
- Identify retention drivers
- Explore customer demographics and service usage
- Build an interactive Power BI dashboard
- Support business decision-making using data visualization

---

## 🛠 Tools Used

- Microsoft Excel (Data Cleaning)
- Power BI (Dashboard Development)

---

## 📊 Dashboard Features

- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate
- Churn by Contract Type
- Churn by Internet Service
- Churn by Payment Method
- Churn by Gender
- Monthly Charges Analysis
- Customer Tenure Analysis
- Interactive Filters (Contract, Gender, Internet Service, Payment Method)

---

## 📈 Key Insights

- Month-to-month contract customers have the highest churn rate.
- Customers using Fiber Optic internet experience higher churn.
- Electronic Check users show the highest customer churn.
- Customers with longer tenure are more likely to stay.
- Contract type significantly impacts customer retention.
